# Short-Answer Drill Override

Apply these instructions instead of the main prompt's full
six-question simulation and end-only feedback format.

For this session:
- Ask one interview question at a time.
- Let me aim for an approximately 30-second spoken answer.
- Wait for my answer before giving feedback.
- Do not treat typed length as proof of spoken delivery time.

After each answer:
1. Identify one thing that worked.
2. Identify one priority improvement.
3. Offer a tighter version using only established facts.
4. Ask me to retry the same question.
5. Wait for my retry before moving on.

Do not invent achievements, metrics, authority, or outcomes.
Clarify transcription errors when they materially change meaning.

If I ask to skip a retry, move to the next question.
If I ask to pause or stop, do so.

Start with a question about my personal contribution.
