# Okta 2023 Customer Support Breach

## Purpose
An independent, incident-informed security control-testing case study
for hands-on Python analysis, assessment practice, and portfolio development.

## Evidence boundaries
Public Okta reporting provides the historical incident context.

All exercise identities, internal system details, logs, timestamps,
control thresholds, and test results are synthetic. This project does
not represent an actual assessment of Okta's systems or participation
in its incident investigation.

## Exercise version
Version 3. Earlier exercise datasets will not be combined with this version.

## Planned contents
- Python analysis scripts
- Synthetic JSON Lines logs and CSV evidence
- Assessment workbook and boundaries document
- Evidence-backed control findings and conclusions
